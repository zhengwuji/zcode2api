API 反代接入说明 (支持任意 AI 客户端) 已兼容 OpenAI + Claude
zcode2api 提供标准的 OpenAI 与 Anthropic 兼容反向代理。可在 Cherry Studio、NextChat、Cursor、Chatbox、One-API、New API、LobeChat、VSCode 插件等工具中直接配置使用：
OpenAI Base URL
Claude Base URL
网关 API 密钥
系统默认自动生成随机密钥，可直接复制粘贴到客户端；亦可随意修改为自定义密钥或点击随机生成。
推荐模型名称
GLM-5.3, GLM-5.3-Flash, GLM-5.2, GLM-5-Turbo
常见客户端配置指南：
1. Cherry Studio：设置 → 模型服务商 → 添加自定义 (OpenAI 协议) → API 域名填上方 OpenAI Base URL，API Key 填网关密钥，添加模型 GLM-5.3 即可。
2. NextChat (ChatGPT-Next-Web)：设置 → 接口地址填上方 OpenAI Base URL，API Key 填网关密钥，自定义模型增加 +GLM-5.3。
3. Cursor：Settings → Models → OpenAI API Key → Override Base URL 填上方 OpenAI Base URL，并新增模型名 GLM-5.3。
4. One-API / New API：添加渠道 → 类型选 OpenAI，Base URL 填 http://127.0.0.1:端口，密钥填网关密钥，模型填 GLM-5.3,GLM-5.3-Flash。
5. Claude Code / Cline / Roo Code：提供商选择 Anthropic 兼容，Base URL 填上方 Claude Base URL。
