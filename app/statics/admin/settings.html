后台鉴权密钥与网关访问控制
鉴权
用于登录此管理后台。修改后需用新密码重新登录。
用于 Cherry Studio、Cursor、NextChat、VS Code 等客户端接入（需携带 Authorization: Bearer <key>）。系统默认已随机生成，您可复制使用，亦可随时修改或重新生成。
后台自动刷新各账号额度与状态的周期。设为 0 关闭自动刷新（仍可手动刷新）。修改后即时生效。
开启后，当调用账号遇到额度耗尽、限流 429、鉴权失败、5xx 错误或接口报错时，在同一次请求中无感自动转移至下一个可用账号继续处理，调用不中断。
开启后，系统在定时监控或检测到额度耗尽时自动探测并领取官方免费体验套餐包。
使用说明
· 在「账号池」粘贴 Coding Plan JWT 或 API Key 即可加入轮询。
· 请求按 round-robin 自动分发；某账号额度用完或失效会自动切到下一个账号。
· 账号额度、套餐状态在「账号池」页实时刷新展示。
· 对话端点：支持标准 OpenAI 协议（/v1/chat/completions）与 Anthropic 协议（/v1/messages）。
